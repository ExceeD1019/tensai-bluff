# お題テンプレート（ジャンル別）

GAME_SPEC.md 3.1 / 3.3 / 7章 の運用メモ。お題は**ジャンルを先に決めてから型に流し込む**と量産しやすい。

## 全ジャンル共通のルール

- 事実は8点。配分は **表層2〜3 / 具体3〜4 / 意外1〜2**（`src/schema/topic.ts` の `TIER_RANGE`）
- **お題の単語を facts と neutralGloss に書かない**（専門家は単語を知らされず、8点から推測する・3.3）
  - 単語を含む固有名（人名・地名・「〇〇法典」等）も避ける。例:「エッフェル塔」→「エッフェル」もダメ
  - 代わりに「この塔」「その料理」「この人物」のように指示語で受ける
  - 単語を特定させる決め手は **意外／具体** の中身で作る（別の固有名・数字・年号はOK）
- `neutralGloss` は**ワードを直接使わない比喩的・抽象的な一行**（潜入者だけが見る）
  - 例:「カレーライス」→「日本中の家庭で親しまれている、ある定番料理」
  - 数字・年号・固有の裏事実は入れない（`GLOSS_LEAK` 警告）
- `guessability`（1〜5）は「単語を知っている人がこの事実を自力で言えるか」の見積り。
  表層は高め（4〜5）、具体・意外は低め（1〜2）。3点以上を guessability≤2 にする（`WEAK_GAP` 対策）
- **`acceptable` 配列を埋める**（単語当て・3.6.1で使う正解バリエーション辞書）。
  `word` 自体は常に正解なので重複させなくてよい。埋める対象の目安:
  - 送り仮名・中黒の有無のゆれ（「エッフェル・塔」的な区切り方など）
  - カタカナ表記のゆれ、英語表記（"black hole" など）
  - 通称・略称（「万里の長城」→「長城」、「ナポレオン・ボナパルト」→「ナポレオン」）
  - 判定は正規化（ひらがな化・全角半角統一・記号除去）した完全一致。**意味が合っているだけの
    言い換え**（「パリのあの鉄の塔」等）は acceptable に入れない — それは仕様として不正解
- `npm run demo` で構造チェック。`WORD_IN_FACT` / `WORD_IN_GLOSS` が出たら単語が漏れている

## 1. 建造物・遺跡

呼称: 「この建造物」「この塔」「この壁」

| tier | 型 |
|---|---|
| 表層 | どこの国・都市にあるか／何のための施設か／材質や形の第一印象／観光・象徴としての知名度 |
| 具体 | 建造年・世紀と依頼者／高さ・長さ・重量などの数値／建材と工法／「世界一だった」記録・世界遺産や七不思議などの格付け |
| 意外 | 完成時と今で見た目が違う（化粧石が剥がされた等）／有名な俗説が誤り（宇宙から見える等）／当初の計画では取り壊す予定だった／単一のものではなく総称 |

避ける固有名: 建造物名を含む人名（設計者名など）。「〇〇塔」「〇〇の長城」の一部語も不可

## 2. 歴史上の人物

呼称: 「この人物」「その将軍」「この画家」

| tier | 型 |
|---|---|
| 表層 | 時代と国・分野（軍人／画家／発明家）／何で有名か（何を成した・何に敗れた）／肖像やイメージの特徴 |
| 具体 | 出身地／生年・没年や在位・活動の年号／代表的な業績・作品・制度（名前に本人の名が入るものは言い換える）／転機になった事件 |
| 意外 | 世間のイメージが誤解（身長・性格など）／短期間で失脚・復帰した／死因や晩年が地味／通説と違う真の功労者 |

避ける固有名: 本人の名・本人の名を冠した法典/定理/賞など

## 3. 食べ物・料理

呼称: 「この料理」「その食べ物」

| tier | 型 |
|---|---|
| 表層 | 主な材料と調理法／発祥の国と現在の広がり／代表的な食べ方・薬味・種類の多さ |
| 具体 | 原型・ルーツになった古い技法や料理／今の形が確立した時代・地域／もとは庶民的／高級だった等の位置づけ |
| 意外 | 本来の目的が今と違った（保存食で主役は別の材料）／海外発祥のものが逆輸入されている／名前や見た目の通説が誤り |

避ける固有名: 料理名を含む種類名（「〇〇巻き」「握り〇〇」等）は言い換える

## 4. 自然現象

呼称: 「この現象」「この光」「この嵐」

| tier | 型 |
|---|---|
| 表層 | どこで・いつ見られるか／見た目（色・形・動き）／観光や人々の関心の対象になっている |
| 具体 | 発生の物理メカニズム／起きる高度・規模・範囲の数値／半球や地域で呼び名・型が分かれる／出やすい帯・条件 |
| 意外 | 地球以外の惑星でも起きる／近年まで正体不明だった別種がある／有名な言い伝えが科学的に誤り |

## 5. 天体・宇宙

呼称: 「この天体」「その星」

| tier | 型 |
|---|---|
| 表層 | どんな性質の天体か（光を出さない／強い重力等）／どうやってできるか／SF・映画での描かれ方 |
| 具体 | 関連する専門用語（境界の名前など）／観測・撮影された年と場所／サイズ・質量のスケール／銀河や太陽系での分布 |
| 意外 | 理論上いずれ消える／外から見ると時間の進み方が違って見える／直接は見えず影・周囲の動きで存在が分かる |

## 6. 動物・生物

呼称: 「この鳥」「その生き物」

| tier | 型 |
|---|---|
| 表層 | 見た目・体型の特徴／飛べる/飛べない等の生態／絶滅・希少・フィクションでの扱い |
| 具体 | 生息地（固有種か）／絶滅・発見の年代／分類上の意外な所属（実は〇〇の仲間）／個体数や標本の状況 |
| 意外 | 絶滅の主因が通説と違う（狩猟より外来種）／完全な標本が残っていない／人間が関わった期間が驚くほど短い |

## 新規お題の追加手順

1. ジャンルを選び、上の型に沿って8点を書く（単語は伏せる）
2. `topics/bank/<id>.json` を作る（形式は既存ファイル参照。型は `src/schema/topic.ts`）。
   `acceptable` 配列（単語当ての正解バリエーション）も同時に埋める
3. `npm run demo` で構造チェック。`WORD_IN_FACT` などの警告をつぶす
4. 事実性は人間が確認する（`source` に出典を残す。`source` は専門家には送られない）
